# 🥗 MacroSnap — AI Nutrition Assistant

MacroSnap is an AI-powered nutrition assistant that analyzes meal descriptions and food images to estimate calories and macronutrients. Built with Python, Streamlit, and Google's Gemini API, it provides an interactive chat experience and allows users to send personalized nutrition summaries directly to WhatsApp using Twilio.

## ✨ Features

* **🤖 AI-Powered Nutrition Analysis:** Estimates calories, protein, carbohydrates, and fats from meal descriptions.
* **📸 Image-Based Meal Analysis:** Upload food images to receive AI-generated meal and nutrition estimates.
* **💬 Interactive AI Chat:** Ask nutrition-related questions and receive contextual responses.
* **📲 WhatsApp Integration:** Send personalized nutrition summaries directly to WhatsApp.
* **👤 User Onboarding:** Collects the user's name and WhatsApp number to personalize the experience.
* **🔐 Secure Configuration:** Uses environment-specific Streamlit secrets to manage API credentials.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Frontend:** Streamlit
* **Generative AI:** Google Gemini API
* **Messaging Integration:** Twilio WhatsApp API
* **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
cd MacroSnap
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install Dependencies

Create a `requirements.txt` file containing:

```text
streamlit
google-genai
twilio
```

Install the required packages:

```bash
pip install -r requirements.txt
```

### 4. Configure API Credentials

Create a `.streamlit/secrets.toml` file in your project directory and add your credentials:

```toml
GEMINI_API_KEY = "your-gemini-api-key"
TWILIO_ACCOUNT_SID = "your-twilio-account-sid"
TWILIO_AUTH_TOKEN = "your-twilio-auth-token"
TWILIO_WHATSAPP_FROM = "whatsapp:+14155238886"
TWILIO_CONTENT_SID = "your-approved-content-template-sid"
```

Replace the placeholder values with your actual credentials. Configure your Twilio WhatsApp sandbox or approved sender and message template as required.

**Security:** Never upload your actual API keys, authentication tokens, or `secrets.toml` file to GitHub. Add `.streamlit/secrets.toml` to `.gitignore`.

### 5. Run the Application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal to start using MacroSnap.

## 🔄 How It Works

1. Enter your name and WhatsApp number.
2. Ask a nutrition-related question or upload a food image.
3. Let Gemini analyze the input and generate estimated nutritional information.
4. Continue the conversation with follow-up questions.
5. Send a summary of the conversation to WhatsApp using Twilio.

## 🎯 Project Objective

MacroSnap demonstrates the practical application of Generative AI, multimodal LLM capabilities, prompt engineering, API integration, and messaging automation in an interactive nutrition assistant.

## ⚠️ Disclaimer

Nutritional values generated by AI are estimates and may not be medically accurate. They should not replace professional dietary advice.
